GitHub sync & access token

The plan is stored as one file in your repository. Reading it is public, so the current plan loads for every visitor with no setup. Saving requires a token, which is kept in this browser only and never written into the site.

To create a token: GitHub, then Settings, Developer settings, Personal access tokens, Fine-grained tokens. Give it access to only the devdinosaur.github.io repository, set Repository permissions so that Contents is Read and write, and choose an expiration you are willing to renew. Paste it above and save. Once per computer.
